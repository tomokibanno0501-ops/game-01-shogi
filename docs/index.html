プライバシーポリシー

最終更新日：2026年9月13日

Moshimo Games（以下「開発者」）は、Androidアプリ「ゆる将棋」（以下「本アプリ」）における利用者のプライバシーを尊重し、以下の方針を定めます。

1. 収集する情報について

本アプリは、利用者の個人情報を一切収集しません。氏名、メールアドレス、位置情報、端末識別子などのデータを取得・保存・送信することはありません。

2. インターネット通信について

本アプリはオフラインで動作し、外部サーバーとの通信は行いません。

3. 広告について

本アプリは広告を表示しません。

4. 第三者への提供について

本アプリは利用者に関するいかなるデータも第三者に提供・共有することはありません。

5. 権限について

本アプリの動作に必要な範囲を超えた端末権限を要求することはありません。

6. 本ポリシーの変更について

本ポリシーの内容は、法令の変更やアプリの機能追加に伴い、予告なく改定される場合があります。重要な変更がある場合は、本ページ上で通知します。
